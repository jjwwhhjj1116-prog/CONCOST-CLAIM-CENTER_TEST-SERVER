- 요청: 우측 일정 카드에 맞춰 늘어난 프로젝트 선택 카드의 빈 하단을 개선한다.
- 기존 선택 도구 아래에 프로젝트 번호·유형, 전체 프로젝트명, 담당 PM·프로젝트 상태, 클라이언트를 배치했다. 중첩 카드·장식·새 버튼은 추가하지 않는다.
